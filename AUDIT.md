# Аудит сайта-портфолио

Отчёт от анализа проекта. Вопросы отсортированы от **критичных** к **незначительным**.

---

## Критические (исправлено в рамках аудита)

### 1. Мобильный overlay не отображался
- **Проблема:** У `.mobile-overlay` было `display: none` без переопределения в `@media (max-width: 768px)`, поэтому затемнённый фон при открытом меню на мобильных не показывался.
- **Исправлено:** В медиазапросе добавлено `.mobile-overlay { display: block; }`.

### 2. Клавиша Escape не закрывала overlay
- **Проблема:** При закрытии меню по Escape снимался класс только с навигации и гамбургера, но не с overlay — затемнение оставалось.
- **Исправлено:** В `initKeyboardNavigation()` добавлено снятие класса с overlay и восстановление `document.body.style.overflow`.

### 3. Неверная ссылка на изображение в JSON-LD
- **Проблема:** В разметке Schema.org указан `og-preview.jpg`, в проекте есть только `og-preview.svg` — ошибка для поиска и превью.
- **Исправлено:** В JSON-LD заменено на `og-preview.svg`.

### 4. Тултип «Скопировано!» у email
- **Проблема:** У `.footer-email.copied::after` используется `position: absolute` при отсутствии `position: relative` у родителя — подсказка могла позиционироваться некорректно.
- **Исправлено:** Для `.footer-email` добавлено `position: relative`.

## Критические (требуют ваших действий)

### 5. Отсутствуют PDF-файлы в репозитории
- В проекте нет файла `a7f3e9d2_resume.pdf` и папки `Сертификаты/` с PDF (МФТИ, Иннополис, Стратоплан и т.д.).
- Все ссылки на резюме и сертификаты ведут на несуществующие ресурсы и дают 404.
- **Рекомендация:** Добавить PDF в репозиторий или положить их в облако и обновить ссылки в HTML.

### 6. Open Graph / соцсети: только SVG для превью
- В мета-тегах указан `og:image` и `twitter:image` на SVG. Многие соцсети (ВК, Telegram, часть превью в поиске) ожидают растровый формат (PNG/JPG, например 1200×630).
- **Рекомендация:** Сделать PNG/JPEG превью (например, `og-preview.png` 1200×630) и указать его в `og:image` и `twitter:image`; SVG оставить как запасной вариант или для PWA.

## Существенные

### 7. Логотип в шапке ведёт на `#`
- Ссылка `<a href="#">` при клике ведёт на верх страницы. Для одностраничного сайта это допустимо, но с точки зрения семантики «домой» чаще делают `href="/"` или `href="#main-content"`.
- **Рекомендация:** Оставить `#` или заменить на `href="/"` и при необходимости обработать переход на главную в JS.

### 8. 3D tilt только у карточек экспертизы
- В коде заявлено «expertise + experience», но `initCardTilt()` обрабатывает только `.expertise-card`; карточки опыта (`.project-card`) наклон не получают.
- **Рекомендация:** Либо добавить в выборку `.project-card` и применить тот же tilt, либо убрать упоминание experience из комментария.

### 9. Несоответствие theme-color на 404 и главной
- В `index.html`: `theme-color` = `#0f0e0d`, в `404.html`: `#050506`. Разный цвет полосы в мобильном браузере.
- **Рекомендация:** Привести к одному значению (например, `#0f0e0d` в 404).

### 10. Sitemap: 404 в индексе
- В `sitemap.xml` указана страница `404.html` с приоритетом 0.1. Обычно 404 не индексируют.
- **Рекомендация:** Удалить URL 404 из sitemap или оставить только для явной политики «показываем красивую 404».

## Средние

### 11. Crawl-delay в robots.txt
- Директива `Crawl-delay: 1` поддерживается не всеми роботами (Google её игнорирует). Используется в основном для части других краулеров.
- **Рекомендация:** Оставить, если нужна вежливая задержка для других ботов, или убрать для упрощения.

### 12. Версии в CONFIG и в HTML
- В `main.js`: `CONFIG.VERSION = '1.0.0'`, в HTML для CSS/JS указано `?v=2.0.0`. При смене версии легко забыть обновить в одном из мест.
- **Рекомендация:** Хранить версию в одном месте (например, в CONFIG) и при сборке/шаблоне подставлять в ссылки на CSS/JS.

### 13. Иконка Telegram в подвале
- Используется символ ✈️; для Telegram чаще используют бумажный самолётик или официальный логотип.
- **Рекомендация:** Заменить на SVG-иконку Telegram или другой узнаваемый символ (например, из иконочного шрифта или спрайта).

### 14. Нет явной подсказки «скопировать email»
- При клике по email он копируется в буфер, но до клика неочевидно (нет title, aria-label или текста вроде «Скопировать»).
- **Рекомендация:** Добавить `title="Скопировать email"` или текст рядом с кнопкой/ссылкой.

### 15. Дублирование ссылки «Связаться»
- В навигации есть пункт «Связаться» (`#contact`) и отдельно кнопка «Обсудить проект» в hero. Это нормально для UX, но при желании можно оставить один основной CTA в шапке (например, только «Обсудить проект» или только «Связаться»).
- На усмотрение; не ошибка.

## Незначительные

### 16. initLearnCards не срабатывает для текущей разметки
- В `initLearnCards()` ожидается, что `.learn-card-head` — это `<button>`, в HTML это `<div>`. Логика аккордеона для карточек обучения не выполняется.
- **Рекомендация:** Либо переделать разметку (head как button с aria-expanded), либо удалить неиспользуемый код.

### 17. Фраза в подвале
- Строка «[INFO] Portfolio ready. yaroshnikita.online · 200 OK» есть на главной, но не на 404. Можно добавить на 404 для единообразия или оставить только на главной.

### 18. Preload шрифтов
- Используется `preload` для Google Fonts; для лучшей метрики LCP можно дополнительно preload ключевой шрифт (например, Syne для заголовков).
- Уже есть preconnect — этого достаточно для большинства случаев.

### 19. Нет явного focus-стиля для карусели
- Карусель образования управляется с клавиатуры (точки), но явные стили `:focus-visible` для точек можно усилить для доступности.
- **Рекомендация:** Проверить видимый focus на кнопках-точках и при необходимости добавить контур.

### 20. Год в подвале
- Указано «© 2026» — при долгой поддержке сайта можно подставлять текущий год скриптом или при сборке.
